# 背景音樂文件說明

這個目錄用於存放遊戲背景音樂文件 (.mp3, .ogg, 或 .wav 格式)

建議的音樂文件：
- `menu.mp3` - 主菜單背景音樂
- `game.mp3` - 遊戲進行中的背景音樂
- `gameover.mp3` - 遊戲結束畫面音樂

## 如何獲取背景音樂
1. 免費音樂網站：
   - incompetech.com (Kevin MacLeod的音樂)
   - freemusicarchive.org
   - ccmixter.org

2. 或使用開源音樂：
   - Jamendo (https://www.jamendo.com/)
   - Free Music Archive

3. 將音樂文件放在此目錄下即可自動使用

## 注意事項
- 確保音樂文件不太大（建議 < 5MB）
- 使用循環友好的音樂（開頭和結尾能自然銜接）
- 音量不要太大，可以在遊戲設定中調整
