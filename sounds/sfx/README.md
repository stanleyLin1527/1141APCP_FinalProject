# 音效文件說明

這個目錄用於存放遊戲音效文件 (.wav 或 .ogg 格式)

建議的音效文件：

## 移動音效
- `move.wav` - 方塊左右移動音效
- `rotate.wav` - 方塊旋轉音效
- `soft_drop.wav` - 軟降音效
- `hard_drop.wav` - 硬降音效

## 消行音效
- `clear_1.wav` - 消除1行
- `clear_2.wav` - 消除2行
- `clear_3.wav` - 消除3行
- `clear_4.wav` - 消除4行（Tetris）
- `tspin.wav` - T-spin 音效

## 其他音效
- `hold.wav` - 使用Hold功能
- `level_up.wav` - 升級音效
- `game_over.wav` - 遊戲結束音效

## 如何獲取音效
1. 可以從免費音效網站下載，例如：
   - freesound.org
   - zapsplat.com
   - mixkit.co

2. 或使用簡單的程序生成音效：
   - Bfxr (https://www.bfxr.net/)
   - ChipTone (https://sfbgames.itch.io/chiptone)

3. 將音效文件放在此目錄下即可自動使用
